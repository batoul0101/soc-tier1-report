# 🔐 SOC Tier 1 – Basic Website Security Assessment

This is a beginner‑level security assessment report created during my SOC Tier 1 training.  
The report simulates a real‑world task where a junior analyst reviews a website’s basic security posture using simple, free tools.

## 📌 What’s inside
- Infrastructure & CDN review  
- DNS configuration check  
- Security headers analysis  
- TLS/SSL certificate inspection  
- Cookie and privacy exposure review  
- Risk summary & beginner‑friendly recommendations

## 🛠 Tools used (simulated)
- IP / CDN lookup  
- DNS lookup  
- HTTP header analyzer  
- SSL/TLS checker  
- Browser developer tools

## 🎯 Purpose
This project demonstrates my ability to:
- Perform structured security assessments  
- Document findings in a clear, report‑friendly format  
- Communicate risks and recommendations to technical and non‑technical audiences  
- Use GitHub to build a professional portfolio in cybersecurity

# 🔐 تقرير SOC Tier 1 – تقييم أمني أساسي لموقع ويب

هذا التقرير هو مشروع تدريبي لمستوى المبتدئين في مجال مراكز العمليات الأمنية (SOC).  
يُحاكي التقرير مهمة حقيقية لمحلل أمني مبتدئ يقوم بتقييم الوضع الأمني لموقع ويب باستخدام أدوات بسيطة ومتاحة مجانًا.

## 📌 ماذا يحتوي التقرير؟
- مراجعة البنية التحتية واستخدام شبكات CDN  
- فحص إعدادات DNS  
- تحليل الرؤوس الأمنية (Security Headers)  
- فحص شهادة TLS/SSL  
- مراجعة ملفات تعريف الارتباط (Cookies) ومدى كشف المعلومات  
- ملخص المخاطر وتوصيات مناسبة للمبتدئين

## 🛠 الأدوات المستخدمة (محاكاة)
- فحص IP / CDN  
- استعلام DNS  
- محلل رؤوس HTTP  
- فحص SSL/TLS  
- أدوات المطور في المتصفح

## 🎯 الهدف من المشروع
هذا المشروع يوضح قدرتي على:
- إجراء تقييمات أمنية منظمة  
- توثيق النتائج بأسلوب تقارير واضح  
- شرح المخاطر والتوصيات لفنيين وغير فنيين  
- استخدام GitHub لبناء محفظة أعمال في مجال الأمن السيبراني

📌 *ملاحظة: جميع العناوين (IP) والمجالات والبيانات المحددة هي نصوص توضيحية (placeholders) للحفاظ على السرية.*
